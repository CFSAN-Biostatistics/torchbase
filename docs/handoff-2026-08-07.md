This sandbox's default `.venv` runs **Python 3.14**, and `miniwdl` 1.8.0
crashes on `--version`/`check`/`run` there (`RuntimeError: There is no
current event loop in thread 'MainThread'` — 3.14 asyncio incompatibility).

available) just for `miniwdl check`. **This means no one has run
`miniwdl run` against `operon_typing.wdl` end to end in this repo yet** —
only static syntax checking + standalone Python smoke tests. First priority
on the next machine: confirm `miniwdl run` actually works there (check its

### 5.2 — Frameshift detection (stub)
`protein_search.wdl` HSPs always report `"frameshift": false`
(`torchbase/workflows/builtin/tasks/protein_search.wdl`, search for
`"frameshift": False`). Real detection needs stitching co-linear HSPs split
by a frame change across a subunit/contig pair — this is `operon_assembly.wdl`'s
job once it has that logic; currently it just passes the flag through.
Needs a frameshifted test fixture to build against (StxTyper's own `test/`
fixtures, per plan §8, are the fastest path — not fetched this session, no
network).

### 5.3 — Phase 0 parity validation (plan §7, §11)
